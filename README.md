## 📂 Featured Data Engineering Projects

### 🛠️ [Project Nexus: Automated API-to-Data Lake Pipeline](https://github.com/AdelYa9/API-Data-Lake-ETL)
An end-to-end automated ETL pipeline engineered to reliably extract, validate, and load complex datasets via external REST APIs into a structured data lake.
* **Extraction & Logic:** Built robust Python extraction scripts utilizing `psycopg2` to poll external endpoints, manage secure token authentication, and process raw JSON payloads.
* **Validation Layer:** Implemented in-memory data cleaning and schema validation rules to ensure data integrity and query-readiness prior to database ingestion.
* **Containerized Ingestion:** Fully containerized the target database environment using **Docker**, optimizing local storage structures for isolated state management and performance testing.

### 🔒 [FinTech SQL Vault & Downstream BI Integration](https://github.com/AdelYa9/fintech-sql-vault)
A secure, scalable PostgreSQL data warehouse built from the ground up as a financial risk engine, featuring enterprise-grade security and semantic layer visualization.
* **Stress Testing at Scale:** Utilized Python and the `Faker` library to synthesize and ingest millions of rows of mock transactional data, allowing for extensive query optimization and load testing.
* **Database Security (RBAC):** Established a rigorous database-level security model, implementing Role-Based Access Control to enforce least-privilege isolation across distinct operational roles.
* **BI Visualization Bridge:** Directly integrated the warehouse with **Power BI**, engineering advanced DAX calculations and configuring Row-Level Security (RLS) within a custom dark-themed charcoal interface optimized for executive-level intelligence.
